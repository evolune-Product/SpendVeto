Cap your AI agent's spend in one line.

An agent in a loop can burn real money before anyone looks — one developer reported ~$6,000 of Claude usage gone overnight from a single command. SpendVeto sits between your agents and the model provider. Every request is checked against a budget before it reaches the model, loops freeze the agent, and the actual cost is booked from the provider's own usage numbers. Your API key passes straight through and is never stored.

1 · Start it

npx spendveto
#   Console   http://127.0.0.1:8402
#   Budget    $25.00/day · $10.00/hour · $5.00/request per agent

2 · Point your agent at it

ANTHROPIC_BASE_URL=http://127.0.0.1:8402 claude          # Claude Code
OPENAI_BASE_URL=http://127.0.0.1:8402/v1 codex           # Codex CLI
OPENAI_BASE_URL=http://127.0.0.1:8402/v1                 # OpenAI SDKs, Cursor, LangChain, Aider…
ANTHROPIC_BASE_URL=http://127.0.0.1:8402                 # Anthropic SDKs

That's it. Set a different budget with spendveto budget 10 ($10/day), watch spend with spendveto status, stop an agent with spendveto freeze <agent> — or use the Console's AI-spend page.

Checked with the real client. On 2026-10-18 Claude Code v2.1.300 ran through the guard with no other configuration: it answered, and the guard booked its main request at $0.012638 — Claude Code had written its 63,180-token system prompt to the one-hour prompt cache, which bills at 2× input, and that's what the guard charged, from the provider's own usage report. (A manual check against a live account, so it isn't in the automated suite; the suite exercises the same wire format against a local mock provider.)

What it stops

Budgets that hold

Per agent: daily (rolling 24h), hourly, per request (worst case, estimated before the call) and per Claude Code session. Over budget → refused before the provider sees it, with a code the agent can read.

Agent loops

The same tool call returning the same result, again and again, freezes the agent until a human looks. Retries of a failed request don't count — that's an SDK being careful, not a loop.

Kill switch

Freeze any agent from the Console or the CLI; every request it makes is refused until you unfreeze it.

Bursts

A per-minute request limit answers with a proper 429 and an integer retry-after, so the client's own retry logic slows down instead of hammering.

Expensive models

Allow or block models per policy; optionally pause any request estimated above a threshold for a human's approval.

Observe first

Observe mode records exactly what it would have blocked and blocks nothing — try a budget on real traffic with zero risk.

Built for the agents you already run

It speaks the Anthropic Messages and OpenAI Chat Completions / Responses formats and follows Claude Code's gateway compatibility guide to the letter: request bodies forwarded byte-for-byte, every anthropic-* header passed through, streams relayed event by event (keep-alive pings included), upstream errors returned unmodified. OpenAI streams are asked for their usage so the cost is the provider's number, not a guess. Prices for current Claude and OpenAI models are built in (as of 2026-10-18) and overridable; a model it doesn't know is priced at the provider's flagship rate and flagged, never guessed low.

For teams

Keys stay on the server

Register an agent and give it a tg_… token instead of a provider key. The guard swaps in a key only it holds; revoking the token revokes access.

One budget across rails

An agent bound to a delegated budget spends tokens, x402 payments and card authorizations against the same cascading cap.

Audit-grade record

Every request — allowed, blocked or observed — lands in the same hash-chained ledger as every payment, with model, usage, price source and session.

What to know. The pre-check uses an estimate (input sized from the request, output from its max_tokens), so the last request allowed under a budget can overshoot it by that one request's difference — the hold exists so parallel requests can't do the same. Traffic on a Claude subscription is metered at API-equivalent prices. Message Batches and other endpoints it can't meter are refused rather than passed through ungoverned. Self-hosted today; a hosted, multi-tenant version is the funded milestone.
