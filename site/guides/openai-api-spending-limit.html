How to set an OpenAI API spending limit per agent, per day

Set OPENAI_BASE_URL=http://127.0.0.1:8402/v1 and SpendVeto checks every Chat Completions and Responses request against a per-agent daily, hourly and per-request budget before it reaches OpenAI. OpenAI's own limits are monthly, per organization or project: alerts are soft, the hard limit returns a 429, and OpenAI notes recorded spend can slightly exceed it.

Python and Node SDKs

# Python
from openai import OpenAI
client = OpenAI(base_url="http://127.0.0.1:8402/v1", default_headers={"x-spendveto-agent": "research-bot"})

// Node
import OpenAI from "openai";
const client = new OpenAI({ baseURL: "http://127.0.0.1:8402/v1", defaultHeaders: { "x-spendveto-agent": "research-bot" } });

Chat Completions and the Responses API both work, streamed or not. For streams, SpendVeto asks OpenAI to include usage so the cost is booked from OpenAI's own numbers, priced from OpenAI's published sheet (as of 2026-10-18). A model the sheet doesn't know is priced at the flagship rate and flagged, never guessed low. Override prices with llm.prices, or set llm.unknownModelRates.

Over budget, the request is refused before OpenAI is called (HTTP 402, code llm_daily_budget and friends). Over the per-minute limit it gets a real 429 with an integer retry-after, so the SDK's own retry logic slows down. Validate the file with spendveto validate before you deploy it.

Honest limits. The pre-check is an estimate (input sized from the request, output from its max tokens), so the last allowed request can overshoot a budget by that request's difference. Endpoints SpendVeto can't meter yet, such as batch jobs, are refused rather than passed through ungoverned.

Questions

Can I set a daily spending limit on the OpenAI API?

OpenAI's documented limits are monthly, per organization or project. A gateway in front of the API, such as SpendVeto, adds rolling daily and hourly caps per agent, checked before each request.

Why does my OpenAI spend go over the hard limit?

OpenAI notes that recorded spend can slightly exceed the limit, because usage is recorded after requests complete. SpendVeto decides before each request on a worst-case estimate and holds that estimate while the request runs, so parallel requests can't all pass the same remaining budget.

Does it work with Codex?

Yes: OPENAI_BASE_URL=http://127.0.0.1:8402/v1 codex.

Can different agents have different budgets?

Yes. Name each agent with the x-spendveto-agent header, or give each a tg_ token in team mode, and every identity gets its own daily, hourly and per-request limits.
