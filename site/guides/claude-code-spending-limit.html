How to set a spending limit for Claude Code

Route Claude Code through SpendVeto with one environment variable — ANTHROPIC_BASE_URL=http://127.0.0.1:8402 claude — and every request is checked against a daily, hourly, per-request and per-session budget before it reaches Anthropic. Claude Code's own --max-budget-usd flag applies only in non-interactive mode, and Console limits are monthly, per organization or workspace.

1 · Start SpendVeto

npx github:revanthrajeev/spendveto
#   Console   http://127.0.0.1:8402
#   Budget    $25.00/day · $10.00/hour · $5.00/request per agent

The first run installs dependencies (about two minutes). Node 22 or newer is recommended. State lives in ~/.spendveto, on your machine.

2 · Point Claude Code at it

ANTHROPIC_BASE_URL=http://127.0.0.1:8402 claude

Request bodies are forwarded byte for byte, every anthropic-* header is passed through, and streams are relayed event by event, following Claude Code's gateway guidance. On 2026-10-18 Claude Code v2.1.300 ran through the guard unconfigured, and its main request was booked at $0.012638 from Anthropic's own usage report.

3 · Set the budget

spendveto budget 10        # $10 a day per agent
spendveto budget 10 3      # …and $3 an hour
spendveto observe          # try it first: record what WOULD be blocked, block nothing

A per-session cap (Claude Code sends a session id with each request) and a per-request ceiling live in the policy file:

{
  "$schema": "https://spendveto.com/schemas/policy-v1.json",
  "llm": { "dailyBudgetUSD": 10, "hourlyBudgetUSD": 3, "sessionBudgetUSD": 2, "maxRequestUSD": 1 }
}

When a request would exceed a budget, it is refused before it reaches Anthropic with HTTP 402 and a machine-readable code (llm_daily_budget, llm_hourly_budget, llm_session_budget, llm_request_cap) plus a suggestion the agent can read.

4 · Watch, and stop an agent

spendveto status           # per agent: spent today, left, requests, top model
spendveto freeze my-agent  # the kill switch
spendveto unfreeze my-agent

The Console's AI spend page shows the same, with budgets you can edit. An agent that keeps making the same tool call and getting the same result is frozen automatically. See stopping runaway loops.

5 · Budgets per teammate or agent

By default everything is one identity, "local". For a team, register each agent in the Console and give it a tg_… token instead of a provider key. The server holds the real Anthropic key (SPENDVETO_ANTHROPIC_KEY), so revoking a token revokes access, and each token has its own budget:

ANTHROPIC_API_KEY=tg_… ANTHROPIC_BASE_URL=http://127.0.0.1:8402 claude
Honest limits. The pre-check uses an estimate (input sized from the request, output from its max_tokens), so the last request allowed under a budget can overshoot it by that request's difference; the actual cost is always booked from Anthropic's usage. Traffic on a Claude subscription is metered at API-equivalent prices, not as a bill. Message Batches are refused rather than passed through ungoverned.

Questions

Does Claude Code have a built-in spending limit?

For non-interactive runs, --max-budget-usd caps one run, and Anthropic notes spend can pass it. The Console sets monthly limits per organization or workspace. For daily, hourly, per-session or per-agent caps on interactive sessions, route Claude Code through a gateway such as SpendVeto.

Will SpendVeto see or store my prompts?

It runs on your machine and forwards requests unchanged. The ledger records the model, token counts, cost, agent and session — not prompts or completions. To detect loops it fingerprints the last tool call and result, and keeps only the hash.

Does it work with a Claude Pro or Max subscription?

Requests pass through and are metered at API-equivalent prices, so the budget reflects what the same usage would cost on the API.

What happens when the budget runs out mid-task?

The next request is refused with HTTP 402 and a code such as llm_daily_budget, before Anthropic is called. Raise the budget with spendveto budget or wait for the rolling window.
